Connexion au dépôt GitHub

Le choix de l'image est enregistré directement dans le dépôt. Pour cela, cette page a besoin d'un jeton d'accès GitHub (à faire une seule fois par appareil) :

  1. Ouvrez github.com → Fine-grained token.
  2. Repository access : « Only select repositories » → choisissez .
  3. Permissions → Repository permissions → Contents : « Read and write ».
  4. Générez le jeton, copiez-le et collez-le ci-dessous.

Le jeton reste uniquement dans ce navigateur.
